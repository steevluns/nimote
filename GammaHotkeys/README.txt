Gamma Hotkeys - Windows 7+
Open the tray icon menu and choose Settings.
Adjust brightness, contrast, gamma and RGB color channels (R/G/B).
To change a shortcut, focus its box and press a combination including Ctrl, Alt or Shift, then choose Save and Apply.
Default shortcuts: Ctrl+Alt+1 gamma low; 2 neutral; 3 gamma high; 4 brighter; 5 darker; 0 reset; Q exit.
Settings are saved in the current Windows user's Application Data folder.
Brightness/color/contrast are implemented through the display gamma ramp, not hardware backlight controls. Some graphics drivers and exclusive-fullscreen games may ignore or reset gamma changes.
