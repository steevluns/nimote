Gamma Hotkeys for Windows 7
Hotkeys: Ctrl+Alt+1 low gamma; 2 neutral; 3 high gamma; 4 brighter; 5 darker; 0 neutral; Q exit.
Build is triggered manually from GitHub Actions. Download the GammaHotkeys-Windows7 artifact.
Note: uses Windows SetDeviceGammaRamp. Exclusive fullscreen games or graphics drivers may ignore/reset it. Brightness presets are gamma-ramp approximations, not panel backlight control.
